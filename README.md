# بوت الأذكار (تيليجرام)

## شو بيعمل
- يبعت ذكر عشوائي كل ١٥ دقيقة من قائمة `azkar` بدون تكرار، ولما تخلص القائمة بيبلش فيها من جديد بترتيب عشوائي جديد.
- يوم الجمعة: أول رسالة بعد منتصف الليل تكون `friday_first_message`، وباقي اليوم يبعت من قائمة `friday_azkar` (نفس منطق عدم التكرار، قائمة منفصلة).
- يوم الأحد الساعة ٨:٠٠ مساءً (قابلة للتعديل): يبعت `sunday_evening_message` مرة وحدة.
- يوم الأربعاء الساعة ٨:٠٠ مساءً (قابلة للتعديل): يبعت `wednesday_evening_message` مرة وحدة.

## خطوات التركيب

### ١) إنشاء البوت
1. افتح تيليجرام وكلم [@BotFather](https://t.me/BotFather).
2. أرسل `/newbot` واتبع التعليمات، رح تاخد **TELEGRAM_BOT_TOKEN**.
3. أنشئ قناة تيليجرام (لو ما عندك)، وضيف البوت كـ **مشرف (Admin)** فيها بصلاحية إرسال رسائل.
4. احصل على **معرّف القناة**: لو القناة عامة، المعرف هو `@اسم_القناة`. لو خاصة، ابعت أي رسالة للقناة وافتح:
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
   ولاحظ قيمة `chat.id` (عادة رقم سالب يبدأ بـ `-100`).

### ٢) رفع المشروع على GitHub
1. أنشئ حساب/مستودع (Repository) جديد على GitHub، وارفع كل الملفات يلي جهزتلك ياها بنفس البنية (خصوصا مجلد `.github/workflows/`).

### ٣) إضافة الأسرار (Secrets)
في المستودع: **Settings → Secrets and variables → Actions → New repository secret**
- `TELEGRAM_BOT_TOKEN` = التوكن يلي أخدته من BotFather
- `TELEGRAM_CHANNEL_ID` = معرّف القناة

### ٤) عدّل ملف azkar.json
افتح `azkar.json` وحط فيه:
- `azkar`: قائمة الأذكار العادية
- `friday_azkar`: قائمة أذكار الجمعة
- `friday_first_message`: أول رسالة تنبعث يوم الجمعة
- `sunday_evening_message` و `wednesday_evening_message`: الرسالتين
- تقدر تغيّر `sunday_evening_time` / `wednesday_evening_time` (صيغة 24 ساعة زي "20:00")

### ٥) التفعيل
- الـ workflow مضبوط يشتغل تلقائيا كل ١٥ دقيقة (`*/15 * * * *`) بمجرد ما ترفع المشروع - ما بدك تعمل شي إضافي.
- تقدر تجربه يدويا من تبويب **Actions → Azkar Bot → Run workflow**.

## ملاحظات مهمة
- GitHub Actions مجاني بس التوقيت التلقائي مو مضمون بالدقة ١٠٠٪؛ ممكن يصير تأخير كام دقيقة وقت الضغط على السيرفرات (عادة مقبول لهاي الحالة).
- الملف `state.json` بيتحدث تلقائيا من الـ workflow نفسه (بيعمل commit بعد كل إرسال) عشان يحفظ مكانه بالقائمة والتواريخ يلي انبعتت فيها الرسائل الخاصة.
- التوقيت الافتراضي هو `Asia/Amman`؛ لو بدك منطقة زمنية تانية، غيّر `TIMEZONE` بملف `.github/workflows/azkar.yml`.
